# Browser game data

Static map chunks consumed by https://abwburns.com/halo-ce-universal/.

The launcher streams these into browser storage, reconstructs each map, and
checks its SHA-256 before marking it complete. manifest.json describes all
24 maps. This branch is separate from the source and Pages deployment.

Halo game data remains the property of its respective copyright holders;
the source-code license does not grant rights to these game assets.
